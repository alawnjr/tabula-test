Estate admin is fundamentally a data pipeline with a legal wrapper. You have a fixed set of facts (decedent's assets, will instructions, beneficiaries, jurisdiction) and a largely deterministic set of outputs (documents, filings, distributions). The lawyer's job is to handle the exceptions — contested claims, ambiguous language, judgment calls. AI should own everything else.

The Ideal System

1. Intelligent Intake

Structured interview that asks ~20 questions and outputs a complete case blueprint: which documents are needed, estimated timeline, jurisdiction-specific requirements, likely complexity flags
Upload the will + any financial docs at intake, AI immediately extracts and populates the case file
Surfaces conflicts immediately (will says X, beneficiary designation on 401k says Y)

2. Living Case File

Single source of truth for every case — assets, liabilities, beneficiaries, deadlines, document status
All documents generated from this structured data, so when a number changes, every downstream document updates automatically
Reconciliation engine that constantly checks: do asset totals match across inventory, accounting, and distribution docs?

3. Document Generation

Templates for every standard document, jurisdiction-aware
Not mail-merge — AI drafts narrative sections (petition language, accounting explanations) from structured data
One-click generation of the full document stack once case data is complete
Tracks document status: drafted → reviewed → filed → accepted

4. Deadline Intelligence

From date of death + jurisdiction + asset types, auto-generates the full compliance calendar
Proactive alerts well before deadlines, not just on the day
Understands dependencies (can't file final accounting until creditor window closes)

5. Beneficiary Portal

Separate interface for beneficiaries to check case status, upload requested documents, sign waivers
Removes the "where is my inheritance" call from the attorney's plate entirely
AI handles routine questions, escalates anything substantive

6. Tax Coordination Layer

Organizes documents for the CPA doing 706/1041 work
Flags tax elections that need attorney/CPA decision (fiscal year election, §645 election, QTIP)
Tracks estimated tax payments during administration
